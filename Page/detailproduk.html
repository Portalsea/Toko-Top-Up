Cara Top Up:

Masukkan Data Akun

Cara Cek User ID & Zone ID

Buka game → klik Profile di kiri atas. User ID ada di bawah nama karakter kamu. Masukkan User ID dan Zone ID saat top up.

Contoh: User ID 12345678 | Zone ID 1234

PENTING:

  • Hanya untuk region Indonesia
  • Pastikan data akun sudah benar. Kesalahan input bukan tanggung jawab toko.
